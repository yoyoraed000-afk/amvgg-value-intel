Pets to invest in

Every pet variant the model expects to rise, ranked from the highest potential down. Potential is the expected change in listed value over the next 30 days, with the odds already priced in. Switch the ranking to value gained or to the safest bets.

Ranked by potential

How to read it. Buy at is today's listed value of that variant; Target is the expected value in 30 days. Potential already multiplies the size of a typical raise by the odds the Value Board makes it, so a 95%-likely small raise and a 55%-likely big one can rank close together. Odds is the chance of any raise of 2% or more. Names open the Explorer, where the potion states and the trades behind the call are listed. The list is only as good as the snapshot date in the top bar; refresh the data before acting on it.

What “profitable” means here. The engine predicts the site’s listed value. You only realise the gain if you can trade the pet at the new value, so the flip score rewards demand and liquidity (how often it appears in listings and completed trades) as well as size and odds. “Available now” is how many active listings offer it. A 20% rise on a 0.014 pet earns little in absolute terms; the “Gain (value)” column shows the expected change in value units so you can compare across tiers.

Computing…

Market signals

What live listings and completed trades say about each item right now. Overpay is the average premium traders paid relative to the listed value; pressure is a z-score combining overpay, want-to-offer ratio and asking premium.

Market-implied values

Solved from completed trades only: the value each item would need for the trades it appeared in to balance. Ridge-anchored to the listed values, so a gap only opens where trades disagree with the list. Both directions are shown, ranked by how far and how well-supported the gap is.

Backtest

The history model is trained on earlier weeks of the update log and tested on the most recent weeks it never saw. The question it answers: given an item's own history, will the Value Board move it up, down, or leave it within the next 30 days?

Running this on amvgg.com

The engine is one dependency-free JavaScript file. It reads the same shapes your database already holds, so it can run as a cron job inside the Next.js app instead of on a scraped snapshot.
